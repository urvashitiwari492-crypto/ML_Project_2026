Project Title
Understanding the Olist Brazilian E-Commerce Dataset

Objective
The objective of this lab is to understand the structure of the Olist Brazilian E-Commerce dataset by exploring multiple related tables, analyzing data quality, and identifying relationships between the datasets.

Dataset
The project uses the Olist Brazilian E-Commerce Public Dataset, which contains information about customers, orders, products, sellers, reviews, payments, and geolocations.
